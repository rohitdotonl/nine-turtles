# slowfeed

**A quiet place to read the web: it shows you what's there, gets out of the
way, and lets you finish.**

slowfeed is a reader for writing published on the open web through RSS, Atom
and JSON Feed. It's designed to be finite, calm and quiet, the opposite of
social media: no notifications, no infinite scroll, no recommendations, no
likes. You choose your sources, read in a clean, consistent layout, and close
it when you're done.

It's built for one person per installation, and it runs as one program plus
one database file.
