<p class="lede">
  Everything in nine turtles works with the keyboard alone. Press
  <kbd>?</kbd> at any time to see these keys in the app.
</p>

<p>
  To press <kbd>G</kbd> then <kbd>U</kbd>, press G, let go, then quickly press U.
  Keys don't do anything while you're typing in a field.
</p>

## Reading

| Key | What it does |
|---|---|
| <kbd>J</kbd> / <kbd>K</kbd> | Next / previous article |
| <kbd>W</kbd> | Write back (a person's article) |
| <kbd>Shift</kbd> <kbd>F10</kbd> or the Menu key | An article's own menu in the list: star, mark read, write back, their page |
| <kbd>Enter</kbd> | Open the article |
| <kbd>S</kbd> | Star or unstar |
| <kbd>H</kbd> | Highlight chosen words |
| <kbd>N</kbd> | Add a note, on the words you've chosen or on the whole article |
| <kbd>V</kbd> | View the original, on the writer's website |
| <kbd>Space</kbd> / <kbd>Shift</kbd> <kbd>Space</kbd> | Scroll down / up a screen |
| <kbd>+</kbd> / <kbd>-</kbd> | Text size |
| <kbd>C</kbd> | Copy link |
| <kbd>Esc</kbd> | Back, or close |

## Go to: press G, then…

| Key | What it does |
|---|---|
| <kbd>G</kbd> then <kbd>U</kbd> | Unread |
| <kbd>G</kbd> then <kbd>S</kbd> | Starred |
| <kbd>G</kbd> then <kbd>N</kbd> | Notes |
| <kbd>G</kbd> then <kbd>A</kbd> | All articles |
| <kbd>G</kbd> then <kbd>,</kbd> | Settings |

## Getting around

| Key | What it does |
|---|---|
| <kbd>/</kbd> | Search |
| <kbd>Shift</kbd> <kbd>J</kbd> / <kbd>Shift</kbd> <kbd>K</kbd> | Next / previous in the sidebar, every row from Unread down, top to bottom: a closed folder's people are passed over |
| <kbd>←</kbd> / <kbd>→</kbd> | Move between the sidebar, the list and the article |
| <kbd>E</kbd> | Edit this person, publication or folder |
| <kbd>O</kbd> | Open or close this folder |
| <kbd>I</kbd> | Info about this person or publication: their page (in any other list, the chosen article's writer's) |
| <kbd>F</kbd> | Full-screen reading: hide the sidebar and the list |
| <kbd>A</kbd> | Add a person or publication |

## Tidying up

| Key | What it does |
|---|---|
| <kbd>Shift</kbd> <kbd>A</kbd> | Mark all as read |
| <kbd>M</kbd> | Mark unread |
| <kbd>U</kbd> | Undo |
| <kbd>R</kbd> | Refresh: show new articles |

## Good to know

- <kbd>Home</kbd> and <kbd>End</kbd> go to the first and last article in the
  list.
- <kbd>↑</kbd> and <kbd>↓</kbd> move inside the part you're in: along the
  sidebar, along the list, or scrolling the article. In a text field or a
  menu, the arrow keys work as they always do.
- A key with nothing to do says why in the note at the bottom: <kbd>K</kbd>
  on the first article says "That's the first article here.", and
  <kbd>U</kbd> with nothing to undo says "Nothing to undo." <kbd>S</kbd>,
  <kbd>M</kbd>, <kbd>W</kbd> and <kbd>N</kbd> with no article chosen say
  "Choose an article first. j chooses the first one."
- The keys are the same for everyone, and can't be changed.
- With <a href="/help/unread-on-or-off/">Unread off</a>, the keys for Unread
  and marking all as read are left out.
