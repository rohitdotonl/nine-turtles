# 0182: Clearer icons, round two

**In one line:** Clearer icons, round two: Previous and Next as chevrons up and down, the sidebar star an outline, Email a person with an @, "All" renamed "All articles" with layers, Your data a storage box, the players at 1.5px, a row's › always 18px

*4 November 2026.*

**Decision.** Seven more icon fixes under the icon rules (decision 0181),
each chosen by the owner from versions shown at real size:

- **Previous and Next** in the phone's article bar are chevrons up and down,
  as the list runs (as Apple Mail does), so Previous no longer looks like
  Back's left chevron.
- **The sidebar's Starred star stays an outline** when Starred is open: the
  grey pill already says where you are, so a filled star only ever means an
  article is starred.
- **Email** (Settings › Account) is a person with an @, so the plain
  envelope belongs to Weekly email alone.
- **"All" is now "All articles"** everywhere it's named (sidebar, list title,
  "Results in All articles", keys, Show in the sidebar), with a layers icon
  in place of the stack, which read as a box or a tray.
- **Your data** is a storage box: its row opens a page, so the arrow onto a
  tray stays only where a file is saved.
- **The players' back 15 and forward 30** use the 1.5px line every other icon
  uses (they were 1.25px).
- **A row's › is 18px everywhere** (it was 16px in some places).

**Why.** Each one broke "clear at a glance" or "one icon, one meaning": two
features shared a drawing, one drawing meant two things, or a sign promised
the wrong action.
