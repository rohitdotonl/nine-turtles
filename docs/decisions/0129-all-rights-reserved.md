# 0129: All rights reserved

*29 October 2026.*

**Decision.** The owner chose to make nine turtles "all rights reserved"
instead of MIT. The code, documents, design, website, name and logo may be
read on GitHub but not copied, changed, shared or reused without the
owner's written permission. `LICENSE` says so, and `server/Cargo.toml`
points to it.

**Why.** nine turtles is opening to readers, and the owner wants to keep
competitors from copying its design and code.

**What it can't do.** Versions published under MIT before this date stay
MIT for anyone who took a copy then. The repository stays public, so the
checks and GitHub's protections stay free; going private is a separate
choice for the owner. The libraries nine turtles uses keep their own
licences, which all allow this.
