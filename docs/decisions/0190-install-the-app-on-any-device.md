# 0190: Install the app on any device

*6 November 2026.*

**Decision.** Settings › Install the app and Settings › Add from anywhere
become one page, **Install the app on any device** (the owner's simplify
review, point 7; the owner chose the name). Three tabs sit at the top,
Computer, Android and iPhone & iPad, as on most help pages; the reader's own
is already chosen. Its steps name their system and browser, since that is
where installing differs (Safari's File › Add to Dock, Chrome's install icon,
Edge's Apps menu, Firefox only on Windows). The other tabs give each device's
steps for any browser, so a reader on a Mac still sees that their phone can
have nine turtles. Each tab ends with how to follow the blog you're on there:
the bookmarks-bar button on a computer, Share on Android, + Add on iPhone.

**Gone.** The bookmark's raw `javascript:` code and its Copy button: nobody
types code into a bookmark by choice, and + Add takes any address. The list
of one line per other device, which the tabs replace. The old address
`/settings/add-from-anywhere` opens the new page.

**Why.** Both pages answered one question, how to use nine turtles beyond
this tab, and a reader shouldn't have to guess which page holds which half.
Three tabs fit across a phone; five (one per system) would not, and Mac,
Windows and Linux share most steps.
