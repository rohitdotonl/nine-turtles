# 0210: Start reading

*6 November 2026. Replaced by decision 0220 (9 November 2026): every list now opens the same quiet way.*

**Decision.** When nothing is open and there's nothing to pick up, and the
list starts with an unread article, the empty reading area no longer says
"Time to read something beautiful.": it has already begun that article. A
small muted line, "Newest unread" ("Oldest unread" with Oldest first), its
title and byline set as the article sets them, its first paragraph (six
lines at most), then one solid button, **Start reading**, which opens it as
choosing its row does. Showing it marks nothing read. Where there's no
reading area beside the list (a phone), the list's first row is begun
the same way (label, larger title, first paragraph, Start reading), still
one row. Not beside search results, nor with Unread off; the
quiet line stays for those, and for a list with nothing unread first. The
owner chose this on 6 November 2026 from the "aha" mockups (idea 1), and
said ship it.

**Why.** The first rule of the "aha" work: get the reader to real reading in
as few presses as possible. An empty page that explains keys asks the
reader to work out what to do; a page that has begun someone's writing asks
only whether to read on. It shows only what the feed contains (the
article's own words), credits the writer in the byline, and fetches
nothing new: the article comes from nine turtles, as when it's opened.

**Changes.** Pick up where you left off (0175) still comes first. The
empty reading area of 0053 and 0142 stays for everything else.
