## 20 November 2026: Changes go live faster

- GitHub's checks no longer download the test browser's fonts and libraries every time, so a round of checks takes about 7 minutes again instead of up to 15.
- Agents open a pull request as soon as a change is built: GitHub runs every browser test while the second reviewer reads it, and all the fixes go in together.
- Threads work side by side instead of waiting for each other to go live.
