## 6 November 2026: Install the app on any device

- Settings › Install the app and Settings › Add from anywhere are now one page, **Install the app on any device**.
- Three tabs at the top, Computer, Android and iPhone & iPad, with yours already chosen. Your tab names your browser, because that's where the steps differ; the others show how to install on your other devices.
- Each tab ends with how to follow the blog you're on: the bookmarks-bar button on a computer, Share on Android, + Add on iPhone.
- The bookmark's raw code and its Copy button are gone. Firefox on Windows now gets its own steps.
