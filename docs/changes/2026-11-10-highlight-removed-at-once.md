## 10 November 2026: A highlight removed the moment it's made goes

- Removing a highlight, or adding a note to it, in the second before it was saved said "The highlight couldn't be removed" and left it there. Now the change waits for the save, then follows, with Undo as usual. That holds for a note box or menu opened while it was saving too, and if the highlight itself can't be saved, a note typed on it stays in its box with "The note couldn't be saved". Browser tests that slow the save on purpose check each case; one of those tests failing now and then on GitHub is how it was found.
