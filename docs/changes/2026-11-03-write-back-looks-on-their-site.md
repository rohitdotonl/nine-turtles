## 3 November 2026: Write back looks on the writer's site

- When you press Write back and nine turtles doesn't know the writer's
  address, it now looks once on their website (the home page, and one
  contact or about page it links to). If it finds an address, it fills it
  in for you to check; if not, it says so and you can paste it as before.
- It looks only when you press Write back, never their articles' pages,
  and never twice for the same writer, whoever presses it.
- The second floor has a new line saying exactly this (decision 0168).
