## 3 November 2026: Installing the app, said plainly

- Settings has a new page, **Install the app**. It says in one sentence what installing gives you (its own icon and window, nothing from an app store, and it updates itself each time you open it), then the steps for the phone or computer you're on, then one line for each other device.
- In Chrome, Edge and on Android, a button installs nine turtles in one press. In the installed app, the page simply says you're already using it.
