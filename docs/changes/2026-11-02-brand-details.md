## 2 November 2026: The brand's small details

- An empty list now says one short fact in the reading font, and how to start when there's something to do. An empty feed says when it was last checked, and a search that finds nothing says what it looked for and where.
- Unread now ends "That's everything for now." The line that ends a list sits on the list's left edge.
- The first welcome says "Hello. Who would you like to read?"
- "Wrong turn?" (the page for an address that leads nowhere) lines up on one left edge, with the same turtles.
- Emails are signed "Rohit", and the note sent when an email changes says to reply for help.
- A new picture shows when someone shares a link to nineturtles.app: the nine turtles and "Read people. Write back." on black.
- The browser-tab icon is now always a black square with a light turtle, so it never disappears on a dark tab.
