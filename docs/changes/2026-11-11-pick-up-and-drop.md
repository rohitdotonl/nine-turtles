## 11 November 2026: Pick up and drop

- Drag someone in the sidebar to the bottom: **Pause** and **Unsubscribe** appear there to drop them on, with Undo. If you saved anything of theirs, it asks first whether to keep it.
- Drag a link from an article, or another tab's address, onto nine turtles to follow that site; drop it on a folder and they go in that folder.
- Drag an OPML file onto nine turtles to import it.
