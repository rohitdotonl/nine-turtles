## 16 November 2026: The list's page, made for two panes

- **One column for the list and the article.** On a computer, the list's titles now start exactly where an opened article's words start, so opening one turns the page in place instead of jumping sideways. Settings and Everyone you follow start on the same line, and an article's ‹ Unread and its tools now sit over its text instead of at the window's corners (decision 0277).
- **When you've read everything, it looks finished.** An empty list now has the page to itself: "Nothing unread." large in the middle, with "New writing will show up here." under it. Starred, Notes, folders and searches that find nothing look the same way. A phone is unchanged.
- **Unread reads like a book's contents page.** Each person's name is set larger, like a chapter heading, and the dates beside the titles are gone: under each name the newest comes first anyway. Every other list still shows dates.
