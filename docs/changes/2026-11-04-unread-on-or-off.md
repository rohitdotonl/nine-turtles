## 4 November 2026: Unread, on or off

- Settings › Reading now has one switch, **Unread**, in place of "Reading mode: Inbox · River". On is how inbox mode worked; off is how river mode worked (no Unread list, no dots, and nine turtles still remembers what you've read).
- If you used River, Unread is off for you; otherwise it's on.
- A single person's or feed's own River setting is gone from Edit. Any articles still unread in a feed set that way are now marked read, so Unread doesn't suddenly fill up.
- The Help page is now "Unread, on or off"; its old address leads there.
