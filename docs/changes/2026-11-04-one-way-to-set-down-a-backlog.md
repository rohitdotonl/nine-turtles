## 4 November 2026: One way to set down a backlog

- Mark all as read (in a list's More menu, or Shift+A) is now the one way to set down unread articles, with Undo as before.
- Catch me up, Mark all above / below as read, Mark older as read (Shift+O) and Settings › Reading › Let unread go after are gone.
- If you had chosen to let unread go, the old articles it was already setting aside stay read, so nothing old comes back into Unread.
