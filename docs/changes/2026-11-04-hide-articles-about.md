## 4 November 2026: Hide articles about…

- Rules are now one sentence: **"Hide articles about [a word] from [everyone / a person]."** Hidden articles are kept and marked read, and search still finds them.
- Start one from an article's **More** menu or from a person's page: both say **Hide articles about…** and open the sentence already set to that person.
- Settings › Rules is now **Settings › Hiding**, and Muted articles is now **Hidden articles**, with **Unhide**. Search marks a hidden article "· Hidden".
- Starring or marking read by rule, matching an author, and rules for a folder are gone. A rule for a folder became one rule for each person in it. Any rule that starred, marked read or matched an author is switched off and kept, and what it already did stays done.
- AI assistants hide articles the same way.
