## 1 November 2026: Small fixes to adding and editing

- In Add a feed, typing a different address after a site offered several feeds now clears the old list, so it no longer looks as if the new address had those feeds.
- Closing Add a feed while nine turtles is still looking no longer pulls you to the new feed afterwards; it just appears in the sidebar.
- Without a connection, Add a feed says so without turning the field's edge red, since the address isn't the problem.
- In Edit feed, "Automatic" no longer touches the edges of its pill.
