## 19 November 2026: One look for each job

- Everything that does the same job now looks and reads the same: one group label, one wordmark, one Undo, one order for a box's buttons, and one word for each act ("Unsubscribe", "Mark as unread", "Text and page").
- Every menu shows an icon before each row: a row's menu, the list's More and the menu on chosen words, as the article's More already did.
- Every number in the app has the plain zero; addresses and codes keep the crossed zero, so 0 and O can't be mixed up.
- The back button's name is no longer cut short, the weekly email opens with "Hello," and Help now uses the app's own words.
